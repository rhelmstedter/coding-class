Julius Caesar sent orders to his generals in a cipher. He replaced every letter with the letter a fixed number of places further down the alphabet. That fixed number is the *key*. The readable message is the *plaintext*. The scrambled message is the *ciphertext*.

Before you teach a computer to do this, do it by hand.

* The Alphabet as Numbers

Python counts from 0, so we will too. Every letter has an *index*.

* Part 1: Encrypt

To encrypt a letter, find its index, add the key, and write the letter at the new index. Spaces stay spaces.

*Example.* Key 3. H is index 7. $7 + 3 = 10$. Index 10 is K.
