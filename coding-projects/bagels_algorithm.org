Bagels is a code-breaking game, a cousin of Mastermind. One player thinks of a secret 3-digit number with no repeated digits. The other player has 10 guesses to find it. After each guess, the code-maker gives clues:

- *Fermi:* one digit is correct and in the right spot.
- *Pico:* one digit is correct but in the wrong spot.
- *Bagels:* no digit is correct.

All the Fermis are listed before the Picos.

Play at least two games with a partner, taking turns as the code-maker. Record one game.

* Part 3: Write the Algorithm

An *algorithm* is a list of steps exact enough that someone else could follow it. Write the steps a computer follows to run Bagels, from the instructions until the player is done playing.

Keep it high level. A step like "generate the clues" is fine. You do not need to explain how. Stuck? Look at the [[https://docs.google.com/document/d/11daAEbLA0tXvxHj2FNLlwytndYRoR_La1kfHOzGOqgY/edit][Example Algorithms]].

#+LATEX: \answerbox{8cm}

1. Guiding questions:
   - Label your algorithm. Where does it use *sequencing*, *selection*, and *iteration*?
   - A game can end in two different ways. Does your algorithm handle both?

2. Trade algorithms with a partner. Follow theirs exactly as written: the secret is 248, and you guess 843 and then 248. Where did it break, or where did you have to guess what they meant? Revise your algorithm if needed.

   #+LATEX: \answerbox{2.5cm}

* Part 4: AP Pseudocode

Rewrite your algorithm using the AP CSP Exam Reference Sheet. The [[https://docs.google.com/document/d/11daAEbLA0tXvxHj2FNLlwytndYRoR_La1kfHOzGOqgY/edit][Example Algorithms]] show what this looks like. You can call these procedures without writing them:

- =generateSecret()= returns a secret number with no repeated digits.
- =getGuess()= returns a valid guess from the player.
- =getClues(guess, secret)= returns the clues for a guess.
- =isCorrect(guess, secret)= returns =true= if the guess matches the secret.
