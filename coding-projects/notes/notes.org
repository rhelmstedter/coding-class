* Tests

Notes are tested only after the Newbie Bites have introduced pytest. A tested notebook's "Your Turn" section saves the student's code with =%%writefile=, and its Run Tests cell downloads the matching test file from =main= and runs it. The results are feedback for the student only; nothing is reported or graded. Each test file lives in a subfolder here named for its notebook, so a change to a test goes live as soon as it is merged into =main=.
