#+title: GPA Calculator: For vs. While

This is the first assignment after the Loops and Dictionaries notebooks. Students build the same GPA calculator twice, once with a =for= loop and once with a =while= loop, and then write about what changed. The two programs are supposed to print the same GPA for the same six grades, so the only thing that differs between them is the loop. That is what makes the comparison worth writing about.

The reflection is weighted more heavily than the code. Writing the calculator is reps: =input()=, string methods, a dictionary lookup, and a running total, none of it new. The questions ask students to find the line that stops each loop, predict what breaks when the counter goes missing, and finally write their own rule for when to reach for each loop. The =done= question sets up the version where a =while= loop is actually the better tool, without making them build it.

This is not the COMP 605 GPA calculator in [[file:gpa-calculator/miniproject2.org][gpa-calculator/]]. That one assumes students have never seen a loop and is much more involved.

** Requirements

*** Code

Both versions must:

1. Store the grade points in a dictionary.
2. Use a loop to ask for a letter grade for each of *6* classes with =input()=. Every prompt says which period it is asking about.
3. Clean up every grade with string methods.
4. Look up each letter grade's point value in the dictionary.
5. Calculate the GPA and print it in an f-string.
6. Given the same six grades, print the same GPA.
7. Run without errors.

*** Written Reflection

Everything is about comparing the loops.

- *Comparing the Loops (1-5):* what the =while= does by hand, the stopping line in each, the missing-counter bug, the =done= thought experiment, and a personal rule with one example for each loop.
- *AP CSP Connection (6-7):* which AP loop matches each version, and how =REPEAT UNTIL= differs from a Python =while= loop.
