The Caesar cipher has a weakness: one key for the whole message. The Vigenère cipher uses a *keyword* instead. Every letter of the keyword is its own Caesar key, and the message cycles through them.

You need a copy of the *Vigenère square*.

* How It Works

1. Write the keyword above the message, one key letter per message letter. Repeat the keyword as many times as you need. A space does not use up a key letter.
2. Find the key letter's row and the plaintext letter's column. The ciphertext letter is where they meet.

* Part 5: Think Like a Programmer

1. A computer does not have a square to look things up in. It has to calculate. What calculation does row C stand for? Row O? Explain how to turn any key letter into a number.
