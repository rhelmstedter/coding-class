Last row: the first R is in the right position (1 black). The secret has only one more R, so only one of the two remaining R pegs in the guess can score, and it scores white. The G is in the wrong position (white). A peg in the secret code can only be matched once. This is the detail students most often miss, and it is the reason Bagels forbids repeated digits.

* The Caesar Cipher on Paper

** Part 1: Encrypt

1. =KHOOR ZRUOG=
2. =CHEUD=. Z is index 25, and $25 + 3 = 28$, which is past the end of the alphabet. Wrap around to the start: 28 becomes 2, which is C.
3. =ZIDRYX SC PEX=
4. If the sum is 26 or more, subtract 26. The rule that works for every letter is "divide by 26 and keep the remainder," which is exactly what =%= does in Python: =(index + key) % 26=.

** Part 2: Decrypt

1. =BE PROACTIVE=
2. =NO WHINING=
3. Subtracting the key can give a negative number. In question 1 that happens at A (index 0) and C (index 2), so add 26: $0 - 7 + 26 = 19$ (T) and $2 - 7 + 26 = 21$ (V). In question 2 it happens at every letter. In Python, =(index - key) % 26= already handles this.

* The Vigenère Cipher on Paper

** Part 1: Encrypt

1. Go to the key letter's row, find the ciphertext letter in that row, and read the letter at the top of that column.

** Part 4: Compare

1. The two Ls became O and P, because they were encrypted with different key letters (D and E). In a Caesar cipher both would become the same letter.
2. No. The first R came from O (with key letter D) and the second came from D (with key letter O).
3. In a Caesar cipher a letter always turns into the same letter, so patterns in the message survive. In Vigenère the same plaintext letter can become different ciphertext letters, and the same ciphertext letter can come from different plaintext letters.
4. =CODECODE=. Column A of the square is the same as the row labels, so encrypting A gives the key letter back. Encrypting a run of As leaks the key.
5. Row D is the Caesar cipher with key 3. Every row is a Caesar cipher, so a Caesar cipher is a Vigenère cipher with a one-letter keyword.

** Part 5: Think Like a Programmer

1. Row C shifts every letter 2 places and row O shifts every letter 14 places. A key letter's number is its position in the alphabet counting from 0, which is its index.
2. D. The keyword repeats every 4 letters, so divide the position by 4 and look at the remainder. Counting from 0 the way Python does, the 23rd letter is at index 22, and $22 \bmod 4 = 2$, which is D.
3. The key becomes a word, so =get_key()= changes, and =translate_message()= has to look up a different shift for each letter and keep track of which key letter comes next. =main()=, =get_mode()=, =get_message()=, and =print_message()= stay the same.

The two messages students hack for their reflection:
